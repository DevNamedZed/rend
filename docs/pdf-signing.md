# PDF Digital Signatures

Rend.Pdf supports PAdES-compatible digital signatures on any PDF document. You can sign PDFs generated by Rend or any existing PDF file.

## Local Certificate Signing

The simplest way to sign a PDF is with a PKCS#12 (.pfx/.p12) certificate file:

```csharp
using Rend.Pdf;

var signer = new Pkcs12Signer(File.ReadAllBytes("cert.pfx"), "password");

using var input = File.OpenRead("document.pdf");
using var output = File.Create("signed.pdf");

await PdfSigning.SignAsync(input, output, new PdfSignatureOptions
{
    Signer = signer,
    SignerName = "Jane Smith",
    Reason = "Document approved",
    Location = "New York, NY",
    ContactInfo = "jane@example.com",
});
```

Or use the convenience overload if you just need a quick signature:

```csharp
var cert = new X509Certificate2("cert.pfx", "password");
await PdfSigning.SignAsync(input, output, cert);
```

## External Signing (HSM, Cloud KMS)

When the private key isn't directly accessible (hardware security module, AWS CloudHSM, Azure Key Vault, Google Cloud KMS), implement `IPdfSigner`:

```csharp
public interface IPdfSigner
{
    Task<byte[]> SignAsync(byte[] data, CancellationToken cancellationToken = default);
    int EstimatedSignatureSize { get; }
}
```

### How It Works

1. Rend prepares the PDF with a signature placeholder
2. Rend computes the byte ranges that need to be signed
3. Your `IPdfSigner.SignAsync()` receives the concatenated byte range data
4. You return a DER-encoded PKCS#7/CMS detached signature
5. Rend patches the signature into the PDF

### Example: Azure Key Vault

```csharp
public class KeyVaultSigner : IPdfSigner
{
    private readonly CertificateClient _certClient;
    private readonly CryptographyClient _cryptoClient;
    private readonly string _certName;

    public int EstimatedSignatureSize => 8192;

    public async Task<byte[]> SignAsync(byte[] data, CancellationToken cancellationToken = default)
    {
        // 1. Hash the data
        byte[] hash;
        using (var sha256 = SHA256.Create())
            hash = sha256.ComputeHash(data);

        // 2. Sign the hash with the HSM-stored key
        var result = await _cryptoClient.SignAsync(SignatureAlgorithm.RS256, hash, cancellationToken);

        // 3. Build the CMS/PKCS#7 envelope
        //    (Use your preferred CMS library — BouncyCastle, .NET SignedCms, etc.)
        return BuildCmsSignature(data, result.Signature, await GetCertificateChainAsync(cancellationToken));
    }
}
```

### EstimatedSignatureSize

The `EstimatedSignatureSize` property tells Rend how many bytes to reserve in the PDF for the signature. The actual signature must fit within this space.

- **8192** is a safe default for most certificate chains
- If your chain includes many intermediate certificates or timestamps, use a larger value (e.g., 16384)
- If the signature exceeds the reserved space, `SignAsync()` throws an `InvalidOperationException`

## Signing Rend-Generated PDFs

You can also sign PDFs as part of the Rend rendering pipeline by setting the signature options on `PdfDocumentOptions`:

```csharp
using Rend.Pdf;

var doc = new PdfDocument(new PdfDocumentOptions
{
    Signature = new PdfSignatureOptions
    {
        Signer = new Pkcs12Signer(pfxBytes, "password"),
        SignerName = "Automated System",
        Reason = "Generated and signed",
    }
});

// ... build PDF pages ...

doc.Save(outputStream); // Output is signed
```

## Dependency Injection

For DI and testing, use `IPdfSigningService` and `PdfSigningService` instead of the static `PdfSigning` facade:

```csharp
services.AddSingleton<IPdfSigningService, PdfSigningService>();

public class DocumentService
{
    private readonly IPdfSigningService _signing;

    public DocumentService(IPdfSigningService signing) => _signing = signing;

    public async Task SignDocumentAsync(Stream input, Stream output, X509Certificate2 cert)
    {
        await _signing.SignAsync(input, output, cert);
    }
}
```

## Technical Details

- Signatures follow ISO 32000-1 (PDF 1.7) and PAdES (ETSI EN 319 142)
- Uses incremental update — the original PDF is not modified, signature objects are appended
- Signature type: `/adbe.pkcs7.detached` with SHA-256 digest
- Invisible signature field (zero-size rectangle on page 1)
- `Pkcs12Signer` includes the full certificate chain (`X509IncludeOption.WholeChain`)
